# Multi-Site-Business-Network-in-the-same-format-as-your-earlier-GitHub-labs.
Cisco Packet Tracer lab connecting Dublin, Cork and Limerick. Covers OSPF, VLANs, DHCP, DNS, NAT/PAT, guest access rules and LACP EtherChannel. Includes the topology, IP addressing, configuration examples, test results and troubleshooting notes.
